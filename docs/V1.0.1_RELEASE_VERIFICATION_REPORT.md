## 5. Human & Authority Boundary Proof

The Desktop Command Center was verified as strictly an **unprivileged Channel/Client**:
1. **No Database Access:** The React application contains zero PostgreSQL or Redis drivers. All communication occurs over loopback HTTP/SSE (`http://127.0.0.1:8420`).
2. **Cryptographic Signing:** Human approvals sign an HMAC-SHA256 preimage (`token-hmac-v1`) via client-side WebCrypto (`SubtleCrypto`). The secret key is never sent across loopback.
3. **Authentication Rejection:** Requests without a valid Bearer token return HTTP 401 Unauthorized.
4. **Forged Decision Rejection:** Decisions submitted with forged or invalid signatures are rejected by the kernel with HTTP 400/401/409.
5. **No Direct Filesystem Escape:** Path traversal attempts (`/api/v1/spaces/../../../etc/passwd`) return HTTP 404.

## 6. HTML Sandbox Security Battery

### Code-Level Verification (`test_html_sandbox_zero_privilege_code_verification`)
Both `src/components/MarkdownMessage.tsx` and `src/components/ArtifactExplorer.tsx` were scanned:
- **Sandbox Attribute:** Both enforce `<iframe sandbox="allow-scripts" ... />`.
- **Zero Same-Origin Guarantee:** Neither contains `allow-same-origin`.
- **Security Boundary:** Because `allow-same-origin` is omitted, the iframe executes in a unique opaque origin (`null`).

### Adversarial Payload Battery (`test_html_adversarial_payload_storage_and_integrity`)
The following adversarial payloads were stored and retrieved with SHA-256 integrity:
1. `window.parent.postMessage('pwned', '*')` $\rightarrow$ Origin `null` restricts parent access.
2. `parent.document.body.innerHTML = 'hacked'` $\rightarrow$ Blocked by browser sandbox (DOM cross-origin violation).
3. `window.top.location = 'https://attacker.com'` $\rightarrow$ Blocked (lacks `allow-top-navigation`).
4. `window.__TAURI__.invoke('system_exec')` $\rightarrow$ Blocked (`__TAURI__` is undefined in untrusted iframe).
5. `localStorage.setItem('ryu_stolen', 'true')` $\rightarrow$ Blocked (`localStorage` access denied in `null` origin).
6. `document.cookie = 'token=stolen'` $\rightarrow$ Blocked (no cookies accessible).
7. `fetch('http://127.0.0.1:8420/api/v1/spaces/default/history')` $\rightarrow$ Blocked (CORS preflight from `null` origin denied).
