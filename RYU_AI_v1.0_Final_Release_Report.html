1. The Six Architectural Laws of SCCA

Law 1 — Everything Happens Inside a Space

Space is the primary isolation and authority boundary. No memory, artifact, task, or agent operates outside a space.

Law 2 — Capabilities Are Requested, Never Owned

Agents and workers do not inherently own capabilities. Every operation requires dynamic admission control and capability gating.

Law 3 — Components Communicate Through Pulses

Zero hidden communication paths or ambient shared state. All inter-component interaction is mediated through typed, schema-validated pulses.

Law 4 — Knowledge Belongs to the Space First

Knowledge is space-local by default. Cross-space promotion requires explicit cryptographic authorization and human oversight.

Law 5 — Humans Define Goals, Ryu Organizes Execution

Human intent governs goals; Ryu organizes planning, assignment, execution, monitoring, and adaptation without silently redefining goals.

Law 6 — Failures Are Contained, Escalated, and Never Silent

Tool and worker failures remain within their originating scope and are surfaced up the chain. Swallowing errors is strictly prohibited.

5. Desktop Command Center & Production Layer

Following formal release verification, the operator interface was packaged as a native desktop application:

  • Embedded Offline Frontend: Tauri v2 embeds the compiled React 18 production bundle (dist/) directly into the executable binary. Completely eliminates development server dependencies (devUrl removed; zero localhost:1420 connection errors).
  • Top Bar Quick Toggle (⚡ LLM): Click [ ⚡ LLM: ON (qwen3.5:4b) ] or [ ⚡ LLM: OFF (Deterministic) ] to switch between local Ollama AI generation and instant deterministic structured templates.
  • Universal Live HTTP Provider: Zero external dependency Python stdlib (urllib.request) provider supporting local Ollama (http://localhost:11434) and OpenAI-compatible remote endpoints.
  • Attention Queue Drawer: Real-time operator oversight with cryptographic HMAC approval verification, live event pulse stream, space task tracking, and audit trails.
  • Conversational Synthesizer: Intelligent typo tolerance (resolving shorthand like "sit" or "wed sit" to "website") with automatic generation of full-stack, single-file HTML/CSS/JavaScript websites and tools.

To eliminate manual command prompt steps, launch automation is deployed at multiple entrypoints:

OR

What the Launcher Automates Automatically:

  1. Infrastructure Preflight: Verifies PostgreSQL 16 (port 5432) and Redis 7 (port 6379); boots Docker containers automatically if offline.
  2. Channel Daemon Preflight: Verifies background service on http://127.0.0.1:8420/api/v1/health; spawns background daemon if not active.
  3. Application Boot: Spawns the self-contained Tauri release binary (ryu-desktop.exe) in a detached desktop window.
